# Library Expansion Input

## Why This Is Not Yet A Session Set

The integrated repo now contains the libraries required by the rebuilt app, but
the remaining historical libraries and demos should only move when there is a
clear consumer and a bounded migration target.

## Likely Scope

- identify the next highest-value component or report packages to import
- decide which historical samples are still worth preserving
- add focused tests for any imported package that becomes app-critical
- tighten namespace/package migration notes as more source moves in-repo

## Open Decisions

- which imports are truly needed for the next product phase
- whether any packages should remain archived permanently
- how much sample/demo material belongs in the canonical repo versus reference storage
